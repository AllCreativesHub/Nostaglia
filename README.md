# 🍸 Nostalgia Lagos — Rooftop Lounge & Resto Landing Page

Step above Lekki Phase I into **Nostalgia Lagos**. A retro-chic rooftop lounge where African soul meets Mediterranean flavors, bespoke cocktails, and panoramic Lagos sunset views.

---

## 🌟 Features & Highlights

- **Aesthetics & Atmosphere:** Deep Obsidian dark mode (`#0A090B`), warm golden amber accents (`#D4AF37`), rich royal purple/plum highlights (`#3A1950`), and champagne cream typography (`#F5EFE6`).
- **Typography:** `Cormorant Garamond` serif headers, `Syne` display font, `Jost` eyebrow labels, and `Inter` body text.
- **Interactive Menu Preview:** Filterable categories (*Small Plates*, *Chef's Mains*, *Platters to Share*, *Crafted Cocktails*) with detailed dish cards and pricing.
- **Table Reservation Console:** Multi-step reservation modal allowing guests to select seating areas (*Rooftop Deck*, *VIP Velvet Lounge*, *Main Dining Hall*, *Sunset Cocktail Bar*), date, time, and party size with direct WhatsApp confirmation.
- **Mobile-First UX:** Floating bottom reservation bar with one-tap WhatsApp concierge integration.

---

## 🛠️ Tech Stack

- **Framework:** React + TypeScript + Vite
- **Styling:** Tailwind CSS v4 + Custom Glassmorphism & Animations
- **Icons:** Lucide React

---

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build Production Bundle

```bash
npm run build
```
